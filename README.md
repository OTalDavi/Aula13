Endpoints usados: PUT e DELETE
PUT é usado para alterar os dados de um recurso já existente,
DELETE é usado para deletar um recurso já existente.
 
Como enviar os parâmetros:
PUT: digitar a URL com o ID do recurso que você deseja alterar e escrever, em JSON no Body, o campo que você queira alterar e o novo valor daquele campo.
DELETE: digitar a URL com o ID do recurso que você deseja deletar.
 
Para instalar o projeto:
Clonar o link do repositório GitHub no GitBash e lançar ele no VsCode, depois entrar com sua conta WSL no terminal do VsCode e então entrar abrir com o localhost.
